=== Confirmed True Positives (Real Bugs) ===
=============================================

=== LARGE GROUPS (10+ findings each) ===

txLock (42 findings, [1654]-[1695]):
  Returns NULL at jfs_txnmgr.c:853 (waitLock path).
  Callers in jfs_dtree.c (dtInsert, dtSplitPage) do NOT null-check before storing tlock.
  Trigger: concurrent JFS operations on same metapage.

xfs_group_get (17 findings, [3]-[19]):
  Returns NULL via xa_load at xfs_group.c:40-47.
  All callers dereference through pag_mount() at xfs_ag.h:107 without null check.
  Affected: xfs_ifree, xfs_reflink_*, xfs_growfs_data, xfs_set_inode_alloc, xfs_iunlink, etc.

bio_alloc_bioset (49 findings, [20]-[68]):
  Returns NULL on mempool failure (bio.c:559,605,634).
  Callers dereference bio->bi_iter.bi_sector or call bio_put() without null check.
  Note: GFP_KERNEL+mempool paths cannot fail; GFP_NOIO/GFP_NOWAIT paths CAN fail.

dm_shift_arg (33 findings, [996]-[1028]):
  Returns NULL when argc exhausted (dm-table.c:821).
  DM constructors parse userspace args; result passed directly to strcmp/kstrtoull/dm_get_device.
  Trigger: malformed DM table from userspace via dmsetup.

cifs_sb_tlink (45 findings, [1946]-[1990]):
  Returns NULL when master_tlink not set up.
  All callers pass to tlink_tcon() without IS_ERR_OR_NULL check.
  Trigger: unmount races, error paths.

snd_ctl_new1 (27 findings, [2416]-[2442]):
  Returns NULL when snd_ctl_new() fails (control.c:289).
  HDA codec/dummy driver callers dereference kctl->id.name/subdevice without null check.

btf_type_skip_modifiers (23 findings, [2086]-[2108]):
  Returns NULL via btf_type_by_id (btf.c:965).
  btf_struct_walk, btf_check_type_match dereference t->info without null check.

sock_from_file (11 findings, [1495]-[1505]):
  Returns NULL when file->f_op != socket_file_ops (socket.c:535).
  vfs_coredump passes result to kernel_recvmsg/kernel_sendmsg without null check.

intel_atomic_get_old_global_obj_state (27 findings, [722]-[748]):
  Returns NULL when state not found (intel_global_state.c:236).
  Callers pass to to_intel_bw_state without null check.

intel_atomic_get_new_global_obj_state (13 findings, [749]-[761]):
  Same pattern as old_global_obj_state (intel_global_state.c:249).

bond_opt_get_val (13 findings, [1197]-[1209]):
  Returns NULL when option not found (bond_options.c:568,573).
  All callers dereference optval->string without null check.

skb_pull_data (18 findings, [616]-[633], [2240]-[2257]):
  Returns NULL when skb->len < len (skbuff.c:2708).
  btintel and bluetooth coredump callers dereference without null check.

__v4l2_subdev_state_get_format (16 findings, [1088]-[1103]):
  Returns NULL at v4l2-subdev.c:1742/1746/1749/1764.
  VIMC test driver callers dereference without null check.

comedi_to_usb_interface (15 findings, [646]-[660]):
  Returns NULL when dev->hw_dev is NULL (comedi_usb.c:25).
  dt9812/ni_usb6501 callers dereference without null check.

__genradix_ptr (~2 out of 110 findings):
  [360] sctp_sendmsg_to_asoc: userspace-controlled stream ID, no null check.
  [361] sctp_getsockopt_pr_streamstatus: userspace-controlled stream ID.
  Remaining 108 findings: stream IDs validated by pre-allocation/iteration.
